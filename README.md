# Agentic Skills

A repository of reusable AI skill definitions — structured prompt instructions that guide AI assistants through specific workflows. Skills are platform-agnostic and tool-independent.

## Skills

| Skill | Description |
|-------|-------------|
| **plan-new-skill** | Conducts an adaptive requirements interview to refine a rough skill idea into a confirmed, actionable brief. Interview only — does not create files or author the skill. |
| **create-skill** | Authors a complete, production-quality skill from a confirmed brief or user-supplied description. Creates the skill directory, SKILL.md, evaluation scenarios, and updates this README. |
